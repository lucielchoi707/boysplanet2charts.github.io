> Interactive chart for MNET Boys Planet 2

## 📙 About this project

Boys Planet 2 Rankings is a website made with React, TypeScript and Recharts. The site compiles information about the trainees from the show, such as:

- Chart with rank per episode
- Star ratings
- Weibo supertopic link (not all trainees have)
- MNET official page link
- Trainee basic information: company, group, birthdate, height, etc
